ToF Theremin Integration Analysis

This document analyzes the integration of the Time-of-Flight Theremin into the expressive-control architecture, strictly adhering to the separation of concerns (Hardware Firmware → Core Logic → Transport).

1. Architectural Flow

Hardware (VL53L5CX)
→
Firmware (I2C Driver)
→
Core (TofThereminProcessor)
→
USB MIDI Transport

2. Sensor Interface & Events

The firmware must not compute MIDI data. Instead, it reads the ToF I2C matrix and emits a generalized SensorEvent. For the multizone VL53L5CX, we map the 8x8 matrix into a 3D vector representing the hand's focal point.

Hardware Note: As detailed in the STMicroelectronics DS13754 datasheet, the firmware driver will configure the VL53L5CX for Continuous Ranging Mode at 60Hz with an 8x8 resolution. The driver calculates the spatial average of active zones (where target status indicates a valid hand reflection) to populate the x_offset and y_offset.
pub enum SensorEvent { /// Emitted by the ToF driver at 60Hz Position3D { source_id: u8, // 0 for Left Hand, 1 for Right Hand z_distance_mm: u16, x_offset: i8, // Horizontal position in the 8x8 grid (-4 to +4) y_offset: i8, // Vertical position in the 8x8 grid (-4 to +4) }, /// Emitted by hardware knobs AnalogControl { source_id: u8, value: u16, } }

3. Core Processing Logic (The "Brain")

Inside expressive-core, we create a new struct TofThereminProcessor that implements the ControlProcessor trait. It receives the 3D position events and uses the existing MPE Voice Allocator to generate InstrumentEvents.

  • Left Hand (source_id: 0) - Volume:
    • If z_distance_mm enters the active threshold: Generate NoteOn.
    • Map z_distance_mm inversely to InstrumentEvent::ControlChange(CC7_Volume).
    • Map x_offset to ControlChange(CC1_Modulation).
  • Right Hand (source_id: 1) - Pitch & MPE:
    • The MPE Allocator assigns a dedicated MIDI Channel.
    • Base note is determined by the initial z_distance at NoteOn.
    • Continuous z_distance changes emit InstrumentEvent::PitchBend on that specific channel.
    • y_offset is mapped to ControlChange(CC4_Timbre).

4. Configuration & Calibration

The system is highly dependent on physical space. The configuration state (parsed from YAML in the simulator or edited via the UI on the physical device) must define the response curves.

# Theremin Configuration Model theremin: left_hand: deadzone_max_mm: 800 # Note On threshold deadzone_min_mm: 50 # Max volume threshold curve: "Exponential" right_hand: scale: "Chromatic" pitch_bend_range: 48 # MPE standard (±48 semitones) mm_per_semitone: 15 # Defines the "fret" distance

The Touch UI Role: The 5" screen updates these parameters in real-time. When a user turns a potentiometer (e.g., to adjust the scale), the AnalogControl event routes through the processor to dynamically mutate this configuration state.
