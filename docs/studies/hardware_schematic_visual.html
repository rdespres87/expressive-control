Hardware Conflict Averted: CrowPanel UART0 vs RP2040-Zero

The 4-pin "UART" connector on the Elecrow CrowPanel 5.0" is physically hardwired to ESP32-S3 GPIO 43/44 in parallel with the onboard CH340G USB bridge. Connecting a coprocessor to this port causes bus driver contention, log spam corruption, and USB flashing lockout. The RP2040-Zero is strictly wired as an I2C Target (Slave @ 0x40) on the shared 400 kHz bus, requiring zero extra cables and achieving ultra-low jitter.
