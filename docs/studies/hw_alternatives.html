6. Crucial Wiring Notes

I2C Address Conflict: Both VL53L5CX sensors have the exact same default I2C address (0x52). If connected directly to the same SDA/SCL lines, they will conflict.

The Solution: You MUST wire the LPn (or XSHUT / EN) pin of each sensor to a separate, dedicated GPIO on the ESP32-S3.

The Boot Sequence:

  1. ESP32-S3 pulls both LPn GPIOs LOW (Sensors OFF).
  2. ESP32-S3 sets Left Sensor LPn HIGH. Left sensor wakes up at 0x52.
  3. ESP32-S3 sends I2C command to change its address to 0x54 in RAM.
  4. ESP32-S3 sets Right Sensor LPn HIGH. Right sensor wakes up at default 0x52.
  5. Result: Both sensors are active. Left is 0x54, Right is 0x52.
ESP32-S3 Pin (Generic Example) Component Pin Requirements
3.3V / VCC VIN (Sensors), VCC (Pots) Must be 3.3V (ESP32 is not 5V tolerant on GPIOs).
GPIO 17 & 18 SDA & SCL (Both Sensors) Requires pull-up resistors (often included on breakouts).
GPIO 4 & 5 LPn / EN (Sensors) Any standard output GPIO.
GPIO 6 & 7 (ADC1) Wiper (Pots) Must be an ADC1 pin (ADC2 is restricted when Wi-Fi is active).
