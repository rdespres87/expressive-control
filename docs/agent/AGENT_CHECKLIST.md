# Agent Session Checklist

## Start
- [ ] AGENTS.md read
- [ ] SESSION_PROTOCOL.md read
- [ ] SESSION_STATE.md read
- [ ] HANDOFF.md read
- [ ] git status
- [ ] git diff
- [ ] baseline tests

## Before coding
- [ ] task sufficiently small
- [ ] observable goal
- [ ] invariants defined
- [ ] explicit scope
- [ ] risks identified

## Before handoff
- [ ] code compilable or failure state documented
- [ ] tests executed
- [ ] SESSION_STATE.md updated
- [ ] HANDOFF.md updated
- [ ] TASKS.md updated
- [ ] single next action defined
- [ ] no critical information kept only in chat
